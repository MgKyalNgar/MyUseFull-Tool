📊 Prompt for Claude Excel

Claude AI ကို Excel သီးသန့်ဆရာတစ်ယောက်လို အသုံးချဖို့ Prompt (7) မျိုး

🔥 အရေးကြီးဆုံးအချက်က ဘာလဲ?

Excel ကို စာအုပ်ထဲက သီအိုရီတွေချည်း ဖတ်ပြီး လေ့လာစရာမလိုတော့ပါဘူး။ Claude AI ကို ကိုယ့်ရဲ့ Excel ဆရာတစ်ယောက်အဖြစ် အသုံးပြုပြီး —

  • ✅ ကိုယ့်ရဲ့ လက်ရှိအရည်အချင်းကို စမ်းသပ်နိုင်တယ်။
  • ✅ ရက် ၃၀ စာ Learning Plan ရေးဆွဲနိုင်တယ်။
  • ✅ ကိုယ်တိုင်လေ့ကျင့်ဖို့ Excel File တွေ ဖန်တီးနိုင်တယ်။
  • ✅ နားမလည်တဲ့ Formula တွေကို အဆင့်လိုက် သင်ယူနိုင်တယ်။
  • ✅ လုပ်ငန်းခွင်သုံး Data တွေနဲ့ လက်တွေ့လေ့ကျင့်နိုင်တယ်။
  • ✅ ကိုယ့်ရဲ့ အဖြေတွေကို ပြန်လည်စစ်ဆေးပြီး အားနည်းချက်တွေကို ပြုပြင်နိုင်တယ်။

သင်ယူချင်စိတ်ရှိပြီး နေ့စဉ် မိနစ် ၂၀ လောက် အချိန်ပေးနိုင်ရင် Excel Skill ကို တစ်ဆင့်ချင်း တိုးတက်အောင် လေ့ကျင့်နိုင်ပါတယ်။

စတင်အသုံးပြုနည်း

  • ၁။ Claude AI မှာ Chat အသစ်တစ်ခုဖွင့်ပါ။
  • ၂။ Settings > Capabilities ထဲဝင်ပါ။
  • ၃။ Create and edit files ကို ဖွင့်ထားပါ။
  • ၄။ အောက်မှာဖော်ပြထားတဲ့ Prompts (၇) ခုကို တစ်ခုချင်းစီ အသုံးပြုကြည့်ပါ။

⚠️ မှတ်ချက်: လုပ်ငန်းခွင်သုံး File တွေ Upload မလုပ်ခင် ကိုယ်ရေးကိုယ်တာအချက်အလက်နဲ့ လျှို့ဝှက်အချက်အလက်တွေကို ဖယ်ရှားထားဖို့ မမေ့ပါနဲ့။
